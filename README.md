# e · EBENE · EDIT · ENGINE

Der Ordner **e/** ist die zentrale Edit‑Ebene des iki1uc‑Systems.
Hier arbeiten alle Tools, Achsen, Räume und Cluster zusammen.

e ist die **Master‑Engine**, die folgende Module verbinden kann:

- WELT (Portal)
- ORT (RESPO)
- P (Palais)
- ANIME (81‑System)
- g (NC‑Commands)
- i (RAW‑Ebene)
- TMP‑Cluster
- NC²‑Routing
- ALL‑Hyperraum
- VECTOR‑Moleküle

e ist vollständig unabhängig und kann jedes Modul laden,
scannen, darstellen, verbinden und tweaken.

## Funktionen

### 1. Edit‑Engine
`EDIT.rom` definiert die globale Edit‑Achse.

### 2. Edit‑Scan
`EDIT.scan` lädt alle Module und erzeugt eine Übersicht.

### 3. Edit‑Pipe
`EDIT.pipe` definiert die Reihenfolge der Tools.

### 4. Edit‑State
`EDIT.state` zeigt den Zustand der Engine.

### 5. ID‑System
`id.html` zeigt Struktur, Status und Engine‑Bindungen.

### 6. Index‑System
`index.html` lädt alle Tools und zeigt sie als Panels.
