# e · EBENE · EDIT · ENGINE

## EBENE
e ist die Layer‑Achse für alle Transformationen zwischen den Engine‑Clustern:
CORE‑X6D, CORE‑NE6D, CORE‑BEN9D, DATA, PORTENGINE, HDFCORE, HIWORLD, XENGINEIX, XENGINEXI, USE‑UI.

## EDIT
e führt Edit‑Operationen aus:
- Struktur prüfen
- Fehler sichtbar machen
- Module scannen
- Engine‑Cluster vergleichen
- TMP‑Reste melden

## ENGINE
e ist die Engine‑Brücke:
- e.room = Identität
- e.move = Bewegung
- e.mode = Betriebsmodus
- e.js = Logik

## Fehler‑Scan
e zeigt Fehler direkt im Browser:
- fehlende Dateien
- falsche Ordnernamen
- doppelte Cluster
- TMP‑Reste
- leere Dateien
